## 🌟 Project Overview

This project was completed as part of the **InternNova Week 3 Assignment: SQL & Excel for Data Analytics**.

The project focuses on using **SQL and Microsoft Excel** to retrieve, filter, organise, analyse, and present data. It includes database creation, SQL querying, joins, subqueries, Excel data preparation, conditional formatting, lookup functions, summary analysis, and data visualisation.
